# 🌍 LinguaAI – Language Translation Tool

## About the Project
LinguaAI is a web-based language translation tool that allows users to translate text between multiple languages through a simple and user-friendly interface.

Developed as part of the CodeAlpha AI Internship – Task 1.

## Features
- Translate text between multiple languages.
- Select source and target languages.
- English, Tamil, Hindi, French, Spanish, German, Japanese and Arabic support.
- Swap source and target languages.
- Copy translated text.
- Character counter.
- Responsive user interface.
- Error handling for translation requests.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Python
- Flask
- MyMemory Translation API

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Install the required package:

   ```bash
   python -m pip install flask
   ```

4. Start the application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   `http://127.0.0.1:5000`

6. Enter text, select languages and click **Translate Now**.

## Translation Service
This project uses the MyMemory Translation API. An active internet connection is required for translation.
